# CloudFlow 智能数据集成平台 — 产品概述与核心概念

> 文档版本：v2.4　|　适用范围：全部套餐　|　最后更新：2026-08-15

## 1. 产品定位

CloudFlow 是一款面向企业的 **SaaS 化实时数据集成平台**，帮助企业将分散在各类业务系统（数据库、SaaS 应用、消息队列、对象存储）中的数据，以**低代码**方式同步到数据仓库或数据湖，为数据分析、BI 报表和 AI 应用提供统一、干净的数据底座。

**核心价值主张：**

- **零运维**：无需自建调度集群，开通即用
- **低代码**：图形化配置同步任务，普通业务人员 30 分钟即可上手
- **增量同步**：基于 CDC（变更数据捕获）实现秒级增量，避免全量重跑
- **可观测**：任务运行状态、同步延迟、数据量全部可视化

## 2. 核心概念

理解以下 6 个概念是使用 CloudFlow 的前提：

| 概念 | 英文 | 说明 |
|------|------|------|
| 数据源 | Source | 数据的来源端，如 MySQL、PostgreSQL、Salesforce |
| 目标端 | Destination | 数据的写入端，如 Snowflake、ClickHouse、数据湖 |
| 连接 | Connection | 数据源/目标端的连接配置，包含地址、凭证、网络设置 |
| 同步任务 | Sync Task | 一条从「源」到「目标」的数据搬运规则，是平台的核心调度单元 |
| 运行实例 | Run Instance | 同步任务的一次执行记录，包含状态、耗时、同步行数 |
| 数据管道 | Pipeline | 多个同步任务组成的有向无环图（DAG），用于编排有依赖关系的任务 |

### 2.1 同步模式

CloudFlow 支持三种同步模式，在创建同步任务时选择：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **全量同步（Full）** | 每次运行都完整读取源表所有数据 | 数据量小、初始化历史数据 |
| **增量同步（Incremental）** | 基于时间戳或自增 ID 只读取新增/变化的数据 | 日常例行同步 |
| **CDC 实时同步（Real-time）** | 解析数据库 binlog/redo log，实现秒级捕获 | 实时性要求高的场景，如订单、风控 |

> **注意**：CDC 实时同步仅对企业版及以上套餐开放，且源端数据库需开启 binlog（MySQL）或逻辑复制（PostgreSQL）。

### 2.2 写入策略

写入目标端时可配置三种策略：

- **Append（追加）**：直接追加，不处理主键冲突
- **Upsert（更新插入）**：按主键更新已有记录，不存在则插入 —— **生产环境推荐**
- **Overwrite（覆盖）**：写入前清空目标表分区，适合全量重跑的维表

## 3. 系统架构

CloudFlow 采用**控制面 / 数据面分离**的架构：

```
┌──────────────────────────────────────────────┐
│  控制面（Control Plane）— 由 CloudFlow 托管    │
│  · Web 控制台 / API 网关                       │
│  · 任务调度器（Scheduler）                     │
│  · 元数据存储（Metadata Store）                │
│  · 监控告警中心                                │
└──────────────────────────────────────────────┘
                    │  下发任务
                    ▼
┌──────────────────────────────────────────────┐
│  数据面（Data Plane）— 运行在客户 VPC 内        │
│  · 同步执行器（Worker）                        │
│  · 数据不落盘到 CloudFlow 侧，保障安全          │
└──────────────────────────────────────────────┘
                    │
                    ▼
        客户数据仓库 / 数据湖
```

**关键点**：数据在客户的 VPC 内直接搬运，**不经过 CloudFlow 的控制面**，这是 CloudFlow 与多数同类产品在安全架构上的核心差异。

## 4. 支持的数据源与目标端

完整清单见《数据源连接器清单》。当前版本支持：

- **关系型数据库**：MySQL、PostgreSQL、SQL Server、Oracle、ClickHouse、Snowflake
- **SaaS 应用**：Salesforce、HubSpot、金蝶云、钉钉
- **消息队列**：Kafka、RabbitMQ
- **对象存储**：AWS S3、阿里云 OSS、MinIO
- **文件**：CSV、JSON、Parquet

## 5. 网络与部署要求

- **出网要求**：数据面 Worker 需能访问 CloudFlow 控制面（`api.cloudflow.io:443`）
- **入网要求**：无需公网入向端口，CloudFlow 不主动连接客户内网
- **私有化部署**：仅 **旗舰版** 支持将整个控制面部署到客户自有环境（Kubernetes）

## 7. 术语速查

- **CDC**：Change Data Capture，变更数据捕获
- **DAG**：Directed Acyclic Graph，有向无环图，用于任务依赖编排
- **Watermark**：水位线，增量同步中记录「已同步到哪里」的标记
- **Backfill**：回填，对历史时间段的数据重新同步
