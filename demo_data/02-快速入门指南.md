# CloudFlow 快速入门指南

> 文档版本：v2.4　|　适用套餐：全部　|　最后更新：2026-08-15

本指南帮助你在 **30 分钟内**完成第一条数据同步链路。

## 前置条件

开始前请确认：

1. 已完成 CloudFlow 账号注册并登录控制台
2. 已开通至少 **基础版** 套餐（免费额度见《套餐与计费说明》）
3. 源端数据库的网络放通了 CloudFlow 数据面 Worker 的访问（见《产品概述》第 5 节）
4. 源端数据库账号具备 `SELECT` 权限；若使用 CDC，还需 `REPLICATION SLAVE` 与 `REPLICATION CLIENT` 权限

---

## 第 1 步：创建连接

1. 进入控制台，点击左侧导航 **「连接管理」→「新建连接」**
2. 选择数据源类型（例如 **MySQL**）
3. 填写连接信息：

   | 字段 | 示例值 | 说明 |
   |------|--------|------|
   | 连接名称 | `prod-order-db` | 建议包含环境与用途 |
   | 主机地址 | `10.0.1.20` | 支持内网 IP 或域名 |
   | 端口 | `3306` | MySQL 默认 3306 |
   | 数据库 | `order_db` | |
   | 用户名 | `cloudflow_ro` | 建议使用只读账号 |
   | 密码 | `******` | 加密存储，创建后不可查看 |

4. 点击 **「测试连接」**，出现绿色「连接成功」提示后点击 **「保存」**

> **提示**：若「测试连接」失败，请先查阅《故障排查手册》中的 `CONN_` 系列错误码。

---

## 第 2 步：创建同步任务

1. 点击 **「同步任务」→「新建任务」**
2. **选择源**：从下拉框选择第 1 步创建的连接，再选择要同步的表
3. **选择目标**：选择目标端连接与目标表
4. **配置同步模式**：
   - 初次同步建议选 **全量同步**，先建立基线数据
   - 后续改为 **增量同步**，并指定增量字段（如 `updated_at`）
5. **配置写入策略**：生产环境建议选 **Upsert**
6. **设置调度周期**：Cron 表达式，例如 `0 */1 * * *` 表示每小时执行一次
7. 点击 **「保存并试运行」**

---

## 第 3 步：验证结果

试运行发起后，进入 **「运行历史」** 页面：

- 状态为 **成功**：可点击查看详情，核对「同步行数」
- 状态为 **失败**：点击报错信息查看错误码，对照《故障排查手册》处理

建议核对目标端数据：

```sql
-- 在目标数据仓库中执行，核对行数与最新时间
SELECT COUNT(*) AS total, MAX(updated_at) AS latest FROM order_db.orders_sync;
```

---

## 第 4 步：配置监控告警（推荐）

1. 进入任务详情页 → **「告警设置」**
2. 配置告警规则，支持以下触发条件：
   - 任务运行失败
   - 同步延迟超过阈值（默认 **30 分钟**）
   - 连续失败次数达到阈值（默认 **3 次**）
3. 选择通知渠道：邮件、钉钉、企业微信、Webhook

---

## 第 5 步：上线调度

确认试运行无误后，在任务详情页点击 **「启用调度」**，任务将按 Cron 周期自动执行。

---

## 常见入门问题

**Q：为什么「测试连接」成功，但试运行报 `PERM_` 开头的错误？**
A：连接测试只验证网络与登录凭证；试运行还需要库表级的读写权限，请检查是否缺少 `SELECT` 权限。

**Q：第一次全量同步很慢怎么办？**
A：可在任务配置中调大 **并发度（parallelism）**，基础版上限为 2，专业版为 8，企业版及以上为 32。

**Q：想要同一条链路既做历史回填又做日常增量，需要建两个任务吗？**
A：不需要。先建立全量任务完成基线，再在同一任务上开启增量；也可使用 **Backfill（回填）** 功能指定历史时间段重跑。
